# MITE: Modern ITE 0.3.9

November 24, 2026. Developed by NingMeng123.

## Changes

- Added the attack-speed gem line for main-hand weapons.
- Added a back-mounted totem, activation animation and sound for Emergency Guard.
- Fixed Zombie Boss enchanted-book rewards and red-diamond stacking and sacrifice feedback.
- Added Wither Plus Inferno skull recognition for Wither summoning, protected Wither Treasures from Wither explosions, and added Enhanced Wither defeat and Resurrection Array rescue advancements.
- ITE settings are now opened from the unified MITE: Modern settings menu.
- Updated the minimum required MITE: Modern version to 0.3.9.

Build file `MITE-Modern-ITE-0.3.9.jar`.

Requires MITE: Modern 0.3.9 or newer, Minecraft 1.21.1, Java 21 and NeoForge 21.1.259 or newer within the 21.1 series. Install the addon and core mod on both client and server.
