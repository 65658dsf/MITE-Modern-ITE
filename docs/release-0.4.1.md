# MITE: Modern ITE 0.4.1

November 28, 2026. Developed by NingMeng123.

## Changes

- Added the Light Core and updated the mithril lantern recipe.
- Increased the Annihilation Skeleton's base attack damage to 80.
- Updated the minimum required MITE: Modern version to 0.4.1.

Build file `MITE-Modern-ITE-0.4.1.jar`.

Requires MITE: Modern 0.4.1 or newer, Minecraft 1.21.1, Java 21 and NeoForge 21.1.259 or newer within the 21.1 series. Install the addon and core mod on both client and server.
