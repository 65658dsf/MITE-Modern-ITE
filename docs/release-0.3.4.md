# MITE: Modern ITE 0.3.4

November 14, 2026. Developed by NingMeng123.

## Changes

- Restored ITE enchantment power variation for enchanting-table rolls and naturally generated random enchantments. The energy multiplier ranges from 0.625 inclusive to 1.125 exclusive.
- Eligible vibranium weapons can receive Sharpness, Smite and Bane of Arthropods together through the enchanting table.
- Adamantium and vibranium equipment can combine conflicting enchantments through the anvil, subject to each enchantment's equipment requirements.
- Corrected material restrictions for Vampiric and club eligibility for Vampiric, Sharpness, Smite and Bane of Arthropods. Wooden clubs and eligible metal clubs now use the corresponding ITE enchantment rules.
- Updated the minimum required MITE: Modern version to 0.3.4.

Build file `MITE-Modern-ITE-0.3.4.jar`.

Requires MITE: Modern 0.3.4 or newer, Minecraft 1.21.1, Java 21 and NeoForge 21.1.259 or newer within the 21.1 series. Install the addon and core mod on both client and server.
