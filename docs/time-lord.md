# 时间领主

开发署名：NingMeng123。

实体 ID：`modern_ite:time_lord`。时间领主属于骷髅类领主，基础生命 180、攻击 12、移动速度 0.28，以秘银剑、全套秘银护甲为初始装备，胸前悬挂时钟，使用流浪者皮肤、1.15 倍显示尺寸及环绕粒子。具有领主的防火和防日晒能力，击杀后按骷髅掉落表结算，玩家击杀额外获得时钟。

时钟通过专属持物层从原副手位置移到胸前，带金色挂绳，跟随躯干的原版／Fresh Animations姿态，穿甲时显示在胸甲外侧。装备存储和掉落保持原样，旧存档中的时间领主直接适用，无需重新生成。

动作沿用现有骷髅的 Fresh Animations 兼容方式：在护甲层构造后重新烘焙标准骷髅模型，显式调用本体的可选动画驱动，保留材质包的嵌套骨骼、装备挂点和近战动作。未安装 EMF／动作包时使用原版骷髅动作。已使用用户的 Fresh Animations 1.10.4 材质包验证实际待机、行走、近战和穿甲绘制。

装备沿用本体现有 `SpecialMobEquipment` 领主生成器：以秘银为材料下限，按出生时的历史最高日期和原有权重生成。只有随机结果的材料档位高于秘银，才升级为对应的艾德曼或振金装备；同档与低档不会替换初始材料。物品品质、附魔和磨损继续由原生生成器处理。装备只在出生时决定，重登、区块加载或日期回拨不重新抽取；旧存档中已有的更强装备也会保留。

交战时还会召唤原版狂风人（`minecraft:breeze`，发射风弹的生物），每100世界tick（正常速度下5秒）最多一只，每位领主累计最多成功召唤6只。需要32格内可见的生存／冒险玩家作为攻击目标，创造／旁观观察不会触发召援。召援计时独立于时间迟滞，不会相互重置；计数和冷却随NBT保存，召唤失败不消耗成功次数。

自然出现的领主沿用开局保护。命令或刷怪蛋手动生成的时间领主，其专属狂风人继承手动遭遇的准入资格，因此第一天也能正常测试召援，无需推进日期；这个来源随NBT保存。碰撞、局部拥挤、召唤者归属、取消回收和6只上限继续生效，其他领主和自然狂风人不获得例外。新生随从直接将领主的玩家目标写入原版狂风人的脑攻击记忆。

只有这些带归属标记的狂风人获得增强：基础生命+50%、攻击属性+25%、移速+10%，并继续参与本体原有的日期成长。原版风弹命中采用固定伤害，因此另在实际风弹伤害路径增加25%，保证远程攻击真正变强；自然狂风人和玩家风弹不受此加成影响。增强使用唯一永久属性修饰符，存档加载不会叠加或回满生命。

默认从历史最高第 96 天起，在主世界和地下世界的敌对生物池中稀有生成，权重为 1。沿用日期、开局保护、光照、额度和拥挤限制。命令和刷怪蛋可以提前召唤：

```mcfunction
/summon modern_ite:time_lord ~ ~ ~
/give @s modern_ite:time_lord_spawn_egg
```

时间领主对玩家交战时，每 240 个世界 tick（正常速度下 12 秒）释放一次时间迟滞，影响球形半径 16 格内有视线的生存或冒险玩家，持续 80 个世界 tick（4 秒）。生成后先等待 80 tick；冷却剩余 20 tick 时出现音效、粒子和施法预警。脱离范围或利用方块遮挡可避免下一次脉冲。

时间迟滞把玩家自身的模拟和输入时钟统一缩放为原速的 **1/5**：正常世界20 TPS时，玩家每五个世界tick推进一次，即4次玩家更新/秒。这里按用户明确指定的1/5倍率实现；原生命令 `/tick rate 5` 从默认20 TPS降至5 TPS，数学上为1/4，两者的目标都是动作过程整体放慢。

移动、起跳、下落、挥手、攻击恢复、弓蓄力、进食、物品冷却、放置和连续右键延迟均按玩家时钟推进。鼠标视角转动同样缩至1/5；快捷栏、滚轮切换、换手、丢弃和背包点击会保留输入，排到玩家动作tick执行，点击／拖拽／松开和Shift／Ctrl状态一起保留。服务端对攻击、使用、交互和容器操作包统一排队，保持原顺序；死亡换体或跨维度时清理旧输入，清除状态后恢复执行。

挖掘直接降低客户端动作和服务端原生挖掘计时的频率，每次挖掘仍保留原生强度，避免重复乘倍率变成1/25。不会施加原版缓慢、挖掘疲劳，也不降低移动速度属性。状态使用时钟图标。

第一人称镜头、第三人称位置、手部使用和挥动、装备切换及角色动作，在整个慢tick内连续插值。网络连接、生命和菜单同步、聊天及退出菜单继续正常响应。其他玩家、生物、投射物、方块与世界时钟保持原速；状态持续时间及其他药水倒计时按正常世界时间推进。

原生状态包负责服务端到客户端同步。客户端在状态计时归零时立即恢复行动，不等待移除包往返。原生清除状态、牛奶、死亡及退出创造／旁观模式的流程沿用原生规则；创造和旁观玩家不会被施加此状态。对非玩家直接施加也会被拒绝。重复刷新或提高药水等级不会进一步叠加时间倍率。

单独测试效果：

```mcfunction
/effect give @s modern_ite:time_dilation 4 0
/effect clear @s modern_ite:time_dilation
```

以下设置可在现有 ITE 设置中修改，并通过现有配置同步机制发送到客户端：

| 配置叶键 | 默认值 | 含义 |
|---|---:|---|
| `time_lord_spawn_limit_day` | 96 | 单独开始日期，与极难怪物总日期取较大值 |
| `time_lord_spawn_frequency` | 1 | 自然权重，0 禁用自然池条目 |
| `time_lord_cast_interval` | 240 | 释放间隔，世界 tick |
| `time_lord_effect_duration` | 80 | 持续时间，世界 tick |
| `time_lord_effect_range` | 16.0 | 球形影响半径，格 |
