# MITE: Modern ITE 0.2.10

开发者：NingMeng123。发布日期：2026-10-24。

本版需要MITE: Modern 0.2.10或更新版本，Minecraft 1.21.1与NeoForge 21.1.259。构建时默认使用相邻本体工程的`build/libs/mite-0.2.10.jar`，生产扩展JAR不嵌入本体或可选依赖。

## 内容

- 自然候选权重支持0～1000000的有限小数，保存、同步和实际抽选均保留数值，兼容旧整数配置。
- 配合本体第1～35天出生装备限制，七种骷髅弓手保留普通无附魔弓，近战变种和Boss不套用弓手例外；第36天恢复原装备流程。
- 清除内部备用出生武器与强制近战缓存，防止早期被限制的武器通过补装、镜像或切换再次出现。旧锁定空手弓手补弓，可见自定义与拾取装备保持原样，Boss非装备能力保留。

本体同期提供矿石默认倍率、长矛与双手武器代价、幻灵刃4～8剑容量及朝向修复。安装时两份JAR配套更新，已有配置不被覆盖。

本轮38项ITE JUnit、335项ITE GameTest和与本体／Simply Swords／Better Combat的134项组合回归通过；正式版另验证0.2.10元数据、最低依赖与生产包边界。完整参数见[刷怪设置](spawning-settings.md)。

正式0.2.10构建的JUnit与配套加载的3项GameTest通过；265个生产类、745项处理后资源及默认TOML逐字节匹配构建输出。与已完成全量回归的0.2.9候选相比，仅版本和最低本体依赖元数据变化。
