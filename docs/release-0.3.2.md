# MITE: Modern ITE 0.3.2

November 7, 2026. Developed by NingMeng123.

## Changes

- Restored batch unpacking for torch bundles. Place bundles in any 1–4 slots of the player crafting grid or crafting table to produce 16, 32, 48 or 64 torches per batch.
- Each batch consumes one bundle from each participating slot. Shift crafting supports repeated batches, and results are split into stacks of up to 16 torches.
- Batch unpacking follows the existing timed crafting system, with recipe synchronization and Crafter support.
- Updated the minimum required MITE: Modern version to 0.3.2.
- Updated the default build filename to `MITE-Modern-ITE-0.3.2.jar`. The default build dependency follows the current version of the core mod.

Requires MITE: Modern 0.3.2 or newer, Minecraft 1.21.1, Java 21 and NeoForge 21.1.259 or newer within the 21.1 series. Install the addon and core mod on both client and server.
