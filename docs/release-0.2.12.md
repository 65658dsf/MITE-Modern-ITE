# MITE: Modern ITE 0.2.12

开发者：NingMeng123。发布日期：2026-10-25。

需要 Minecraft 1.21.1、NeoForge 21.1.259 和 MITE: Modern 0.2.10 或更新版本。扩展版本为 0.2.12，本体最低依赖保持 0.2.10。

## 修复内容

- 火把捆的四种合成和单捆分解恢复旧版制造计时。0 级无加速时，背包合成 138 tick（6.9 秒），燧石工作台合成 114 tick（5.7 秒），分解 25 tick（1.25 秒）。
- 补齐全部 154 个扩展普通配方和原版灯笼的制造难度；玩家、自动合成器与工作台 JEI 读取同一规则。Shift、数字键、副手和连续制造均受服务端计时约束。
- 修正八种金属棒维修、升材缺失的来源难度，以及三档保留材质灯笼的合并维修计时。

完整旧版证据、配方难度与验证见[配方制造耗时](crafting-time.md)。熔炼、强化和独立金属升级炉继续使用各自的计时系统。本体现代新增配方中仍有 443 项尚待适配耗时，详见审计范围。

## 验证与安装

生成表一致性检查、构建、38 项 JUnit 和 342 项服务端 GameTest 全部通过。发布包另核对 0.2.12 元数据、全部生产类与处理后资源，排除测试类、本体类与参考 JAR。

使用 `build/libs/modern-ite-0.2.12.jar` 替换旧扩展 JAR，保留满足最低版本要求的本体。此包不嵌入本体或 JEI。

成品大小 1,501,190 字节，SHA-256：`054ca56765b431682add560cfb9ade285c3b18c2fb6857d9fe151e78138aff3b`。280 个生产类、746 个处理后资源与构建输出逐字节一致；相较上一轮已验证修复包，仅模组版本元数据变化。本次日志和包审计保存在 `build/verification/release-0.2.12/`。
