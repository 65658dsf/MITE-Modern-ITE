# MITE: Modern ITE 0.4.0

November 26, 2026. Developed by NingMeng123.

## Changes

- Fixed ITE monster growth, burn damage and fuse behavior.
- Added the Underworld cooldown countdown to the HUD.
- Updated Iris compatibility so lantern night vision is recognized while shaders are enabled.
- Players can now resist the upward camera movement caused by zombies.
- Updated the minimum required MITE: Modern version to 0.4.0.

Build file `MITE-Modern-ITE-0.4.0.jar`.

Requires MITE: Modern 0.4.0 or newer, Minecraft 1.21.1, Java 21 and NeoForge 21.1.259 or newer within the 21.1 series. Install the addon and core mod on both client and server.
