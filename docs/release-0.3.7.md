# MITE: Modern ITE 0.3.7

November 18, 2026. Developed by NingMeng123.

## Changes

- Unified skeleton splitting eligibility across spawn initialization and death handling. Skeleton bosses and mirror skeletons are excluded, including entities loaded with saved compressed traits.
- Updated the models, textures, glow layers and particles for blaze, lightning and floating skeletons.
- Moved high-tier tools and melee weapons to progressive native smithing through iron, ancient metal, mithril, adamantium and vibranium. Added iron, ancient-metal, mithril and adamantium knives and their upgrade chain. Upgrades carry quality, enchantments, growth, gems and forging data and transfer durability loss proportionally.
- Set the default hostile natural-spawn scheduling interval to 3 ticks and synchronized the bundled defaults and setting descriptions.
- Vibranium forging-table and furnace crafting now require two netherite ingots each, with manufacturing difficulty calculated from the updated ingredients. Forging grades VII, VIII and IX now also consume 1, 2 and 3 netherite scraps respectively.
- Removed innate fire immunity from adamantium and vibranium equipment. Netherite-trimmed player armor receives dropped-item protection against fire and lava, including equipment restored from existing saves. Added native armor-trim support for MITE armor and the corresponding tooltip.
- Eligible lords now have a 10% chance to drop one randomly selected vanilla armor-trim smithing template.
- Updated nether adamantium ore to yield raw adamantium, with Silk Touch and MITE Fortune support.
- Updated the minimum required MITE: Modern version to 0.3.7.

Build file `MITE-Modern-ITE-0.3.7.jar`.

Requires MITE: Modern 0.3.7 or newer, Minecraft 1.21.1, Java 21 and NeoForge 21.1.259 or newer within the 21.1 series. Install the addon and core mod on both client and server.

## 中文更新日志

- 统一骷髅生成初始化与死亡结算的分裂资格判定。骷髅 Boss 和镜像骷髅禁止分裂，并覆盖带有旧存档压缩特性标记的实体。
- 更新烈焰、闪电与漂浮骷髅的模型、贴图、自发光层和粒子表现。
- 高阶工具和近战武器改为通过原版锻造台逐级升级，材质顺序为铁、远古金属、秘银、艾德曼、振金。新增铁、远古金属、秘银与艾德曼小刀及其升级链。升级继承品质、附魔、成长、宝石和强化数据，并按比例继承耐久损耗。
- 敌对生物自然刷怪调度默认间隔设为 3 tick，并同步内置默认值与设置说明。
- 振金强化台与振金熔炉配方各需要 2 个下界合金锭，制造难度按更新后的材料计算。强化 VII、VIII、IX 级分别额外消耗 1、2、3 个下界合金碎片。
- 移除艾德曼和振金装备的自带火焰免疫。使用下界合金纹饰的玩家护甲在掉落后获得火焰和熔岩保护，覆盖旧存档恢复的装备。补齐 MITE 护甲的原版纹饰支持与对应提示。
- 符合条件的领主新增 10% 概率掉落 1 个随机原版盔甲纹饰锻造模板。
- 下界艾德曼矿石改为产出粗艾德曼，支持精准采集和 MITE 时运规则。
- 最低本体依赖更新为 MITE: Modern 0.3.7。

构建文件为 `MITE-Modern-ITE-0.3.7.jar`。

需要 MITE: Modern 0.3.7 或更新版本、Minecraft 1.21.1、Java 21，以及 NeoForge 21.1.259 或更新的 21.1 系列版本。客户端和服务端均须安装附属及本体。
