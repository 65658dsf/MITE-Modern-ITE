# MITE: Modern ITE 0.3.3

November 10, 2026. Developed by NingMeng123.

## Changes

- Added sweeping highlights and brief corner sparkles to all 65 gemstone items, including the five gemstone shards. Each cycle returns to the original colors, with staggered pauses of 1.5–5 seconds between highlights.
- Fixed gemstone animations freezing when Sodium's visible-texture optimization is used together with Accelerated Rendering's cached item rendering. The compatibility covers inventory and held-item rendering.
- Added an optional faceted 3D gemstone resource pack for all 65 items, with six grades of gemstone cuts and animated highlights. Install `MITE-Modern-ITE-3D-Gems-1.21.1.zip` separately in the instance's `resourcepacks` folder and enable it in the resource-pack menu.
- Added a two-handed gemstone inspection animation through the optional Punchy integration. Press the default `I` key while holding a gemstone to lift it, pass it between the hands, examine it up close and put it away. The sequence lasts about 5.2 seconds at the default animation speed and supports right-handed, left-handed and offhand use.
- Inspection supports both the standard gemstone appearance and the optional 3D pack.
- Updated the minimum required MITE: Modern version to 0.3.3. The default build filename is `MITE-Modern-ITE-0.3.3.jar`.

Requires MITE: Modern 0.3.3 or newer, Minecraft 1.21.1, Java 21 and NeoForge 21.1.259 or newer within the 21.1 series. Install the addon and core mod on both client and server. Punchy is required for the inspection animation, and the 3D resource pack is an optional client-side appearance download.
