# 僵尸领主与精英领主召援

开发与验证：NingMeng123，2026-10-28。

按本轮要求，普通僵尸领主和僵尸精英领主均使用旧版精英领主的召援规则。普通领主原先没有这项能力，本轮为其新增；精英领主修复召援准入、失败计数和随从力量效果。

## 召援规则

- 服务端有存活的生存／冒险玩家目标时推进计时，首只及后续每只均等待51个有效tick；失去目标、创造或旁观玩家目标时暂停。
- 每次等概率选择矿工僵尸、食尸鬼、尸妖、亡魂之一，继承领主攻击目标，以该随从自己的正常出生流程初始化装备。
- 随从获得永久力量Ⅰ，并延长自然消失计时；保留现有有界碰撞检查、附近拥挤限制和同一召唤者最多8只存活随从的限制。
- 每个领主累计最多成功召唤24只。碰撞、拥挤或事件取消导致失败时不消耗次数，51个有效tick后重试。成功次数和剩余计时随NBT保存，不在加载时重置。
- 命令／刷怪蛋生成的这两种领主，其四类专属随从继承手动遭遇准入，允许在第一天和开局保护期间召援。标记包含召唤者UUID并校验随从类型；自然领主及其他随从继续遵循原来的自动生成限制。
- 旧精英领主如果仍在从未结束的开局保护期、来自命令／刷怪蛋且尚未迁移，恢复其被旧逻辑浪费的召援额度一次。这段时期此前不可能成功生成随从；保护已结束或已迁移的存档不重置次数。

## 手持与护甲

本轮按用户要求，两种领主的新生默认装备均为振金战锤、振金头盔／胸甲／护腿／靴子，副手为空。参考JAR中的普通领主原为振金剑、精英领主为振金战锤；普通领主换锤属于本轮定制。

五件装备逐件使用本体`R196MobEquipment.generated`，恢复旧版出生装备的随机附魔、品质和磨损流程；普通领主的源附魔开关采用`min(最高日期, enhance_limit) > 64`，精英领主采用`最高日期 > 64`。本体当前的全局日期附魔补充继续生效，不额外叠加第二套附魔抽签。振金默认品质为平均，不强制高品质，也不固定保护Ⅴ或锋利Ⅴ。速度Ⅰ和力量Ⅰ保留。

地底维度另外按旧版为主手锋利和四件护甲保护各独立抽取`0～5`级，只提高已有等级，0不增加；仅新生装备执行一次，不在读档时重抽。随机配发盾牌被关闭，后续拾取仍走原有规则。

已初始化的普通领主只在旧默认振金剑数量为1、非拾取保证掉落、显式组件仅包含磨损／附魔／品质时换成战锤，保留组件与磨损比例。命名、描述、自定义数据、属性覆盖、拾取物及其他类型武器均保留。已有护甲不重新生成，装备修订号确保升级只执行一次。

## 拾取武器不降级

本体原有装备升级逻辑会直接优先接受更高品质的同类物品，未同时比较材料与攻击属性，可能让平均品质振金武器被高品质铜武器替换。两种领主现在对主手替换额外检查：已知材料档次不能降低，常驻攻击属性不能下降，锋利及使用原生`DAMAGE`效果的伤害附魔等级不能降低；品质、耐久等剩余选择继续遵循本体原有规则。

主动寻找装备、地面接触拾取和装备接收共用同一限制，拒绝时不会掉落原武器或消耗地上物品。比较常驻攻击属性时只计算主手`ATTACK_DAMAGE`及其原生加法／乘法修饰，不把攻速等其他属性混入。未知第三方材料通过攻击属性兜底。空手仍可拾取，护甲、副手盾及其他僵尸的规则保持原样；同品质更强物品是否吸引主动追逐仍由本体的品质优先策略决定。

## 旧版掉落

两种领主的掉落保持现有的ITE与Extreme合并行为：近期有玩家参与击杀时，普通领主掉钻石、精英领主掉绿宝石，数量均为`min(3, day / 32 + 1)`，整数除法，1～31天1颗、32～63天2颗、64天起3颗。不追加普通僵尸腐肉，也不随抢夺提高奖励数量。装备掉落仍走独立流程。

ITE单独运行时普通领主固定掉3颗钻石；Extreme的`EntityZombieLordMixin.dayUpDrop`通过`@ModifyConstant`修改此数量，因此应以两个参考JAR组合后的行为为准。
