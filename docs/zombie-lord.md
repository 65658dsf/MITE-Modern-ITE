# 僵尸领主与精英领主召援

开发与验证：NingMeng123，2026-10-28。

按本轮要求，普通僵尸领主和僵尸精英领主均使用旧版精英领主的召援规则。普通领主原先没有这项能力，本轮为其新增；精英领主修复召援准入、失败计数和随从力量效果。

## 召援规则

- 服务端有存活的生存／冒险玩家目标时推进计时，首只及后续每只均等待51个有效tick；失去目标、创造或旁观玩家目标时暂停。
- 每次等概率选择矿工僵尸、食尸鬼、尸妖、亡魂之一，继承领主攻击目标，以该随从自己的正常出生流程初始化装备。
- 随从获得永久力量Ⅰ，并延长自然消失计时；保留现有有界碰撞检查、附近拥挤限制和同一召唤者最多8只存活随从的限制。
- 每个领主累计最多成功召唤24只。碰撞、拥挤或事件取消导致失败时不消耗次数，51个有效tick后重试。成功次数和剩余计时随NBT保存，不在加载时重置。
- 命令／刷怪蛋生成的这两种领主，其四类专属随从继承手动遭遇准入，允许在第一天和开局保护期间召援。标记包含召唤者UUID并校验随从类型；自然领主及其他随从继续遵循原来的自动生成限制。
- 旧精英领主如果仍在从未结束的开局保护期、来自命令／刷怪蛋且尚未迁移，恢复其被旧逻辑浪费的召援额度一次。这段时期此前不可能成功生成随从；保护已结束或已迁移的存档不重置次数。

## 旧版掉落

两种领主的掉落保持现有的ITE与Extreme合并行为：近期有玩家参与击杀时，普通领主掉钻石、精英领主掉绿宝石，数量均为`min(3, day / 32 + 1)`，整数除法，1～31天1颗、32～63天2颗、64天起3颗。不追加普通僵尸腐肉，也不随抢夺提高奖励数量。装备掉落仍走独立流程。

ITE单独运行时普通领主固定掉3颗钻石；Extreme的`EntityZombieLordMixin.dayUpDrop`通过`@ModifyConstant`修改此数量，因此应以两个参考JAR组合后的行为为准。
