# MITE: Modern ITE 0.3.8-bugfix1

November 21, 2026. Developed by NingMeng123.

## Changes

- Upright and flat Wither summoning structures now recognize Wither Plus’s Inferno Wither Skeleton Skull in any of the three skull positions, including when a wall-mounted skull completes the structure. The summoned boss displays the name “Enhanced Wither.”
- Skull summons now work in the Underworld, including below Y=0 and during the first-day grace period for hostile spawns.
- The five Wither Treasures dropped by an Enhanced Wither now survive Wither explosions, including skulls that hit after the boss dies.
- Added three advancements. “I'm a Speed Bump” and “Wither: I'm No Maggot” unlock when an Enhanced Wither kills you or a bound Resurrection Array saves you from its fatal damage. Damage over time from the Wither effect also counts when the kill is credited to the boss. “Wither, You're Still a Maggot” unlocks when you kill an Enhanced Wither.

Build file `MITE-Modern-ITE-0.3.8-bugfix1.jar`.

Requires MITE: Modern 0.3.8-bugfix1 or newer, Minecraft 1.21.1, Java 21 and NeoForge 21.1.259 or newer within the 21.1 series. Install the addon and core mod on both client and server.

## 中文更新日志

- 竖放或平放的凋零召唤阵都能识别 Wither Plus 的炼狱凋零骷髅头。三个头颅位置任放一个炼狱头即可，包括最后从侧面放上的头颅。召唤成功后，Boss 血条显示「强化凋零」。
- 修复地底世界手动摆头召唤凋零被自然刷怪限制拦截的问题。在首日保护期和 Y=0 以下也能完成召唤。
- 强化凋零掉落的五个凋零宝藏现在能抵御凋零造成的爆炸，包括 Boss 死后才命中的凋零头颅弹。
- 新增三个成就。被强化凋零击杀，或在它造成致命伤时由已绑定的复活传送阵救回，可获得「我是减速带」和「凋零：我不是蛆」。能归因到该 Boss 的凋零效果持续伤害也计入。亲手击杀强化凋零，可获得「凋零你还是蛆」。

构建文件为 `MITE-Modern-ITE-0.3.8-bugfix1.jar`。
