## 明确的现代适配

玩家经验等级不封顶。生命值使用：

```text
levelBase = min(60, 6 + 2 * floor(max(level, 0) / 5))
gemHealth = 四件护甲各自最高生命宝石阶数之和，最多 24
maximumHealth = min(dayCap, levelBase + gemHealth)
dayCap = 历史最高日 < 96 时 20，96–127 时 30，128–169 时 40，170 起不再限日
```

基础生命在 135 级达到 60；170 日起满级生命宝石可把总生命提高至 84。日数复用基础 `BloodMoonInvasion.highestDay` 的唯一存档，调回时间不会重新封锁；客户端沿用基础同步结果，不重新计算。源配置 `maxLevelLimit=300` 导致的基础生命 `300/5=60` 被保留为生命曲线的独立平台，不恢复玩家 300 级玩法上限。

营养容量使用 `min(20, 原容量 + 四件护甲营养宝石阶数之和)`。低等级可提前达到 20，高等级原容量已满时营养宝石不再有效；这明确保留了用户选择的营养 20 上限。生命宝石不经独立属性修饰器绕过日上限。

宝石效果映射如下；每件装备的同类宝石只计最高阶，孔位不限制宝石种类，实际作用仍取决于装备位置和用途。

| 宝石 | 每阶效果与生效对象 |
| --- | --- |
| 攻击 | 主手装备攻击 +1 |
| 生命 | 穿着的四件护甲各 +1 生命，受总日上限控制 |
| 保护 | 对应护甲槽 +0.25 现代护甲值；四个槽使用独立属性 ID，可叠加 |
| 恢复 | 每阶增加 12.5% 实际自然恢复量，四件护甲相加 |
| 效率 | 有效工具挖掘速度加 `阶数² + 1`，仍经过原本饥饿、等级等限制 |
| 耐久 | 每阶 5% 独立几率免除一次耐久消耗，最高 30%；基础耐久附魔继续独立处理 |
| 速度 | 鞋子每阶 +5% 基础移动速度 |
| 防火 | 胸甲每阶减少 12.5% 火焰伤害；绕过附魔保护的伤害不受影响 |
| 防爆 | 护腿每阶减少 12.5% 爆炸伤害；绕过附魔保护的伤害不受影响 |
| 饱食 | 四件护甲每阶容量 +1，总容量仍最多 20 |

可镶嵌对象使用基础已识别的工具/武器档案和人形护甲。弓、盾、马铠不因持有宝石自动获得额外槽位。修理和其他装备维护通过基础扩展接口保存孔位、磨具次数、独立锻造等级；普通附魔和成长副词条保持各自独立。

首个发布的数据组件 schema 为 1，注册键是 `modern_ite:gem_sockets_v1`、`modern_ite:grindings_v1`、`modern_ite:forge_grade_v1`，均有持久化及网络 codec。以后改变格式应使用新版本键并显式迁移，不覆盖已发布版本的旧解码格式。

磨具不直接赠送成长等级或随机副词条，只扩充原本材料上限。防护宝典使用当前附魔型成长副词条，不额外安装 ITE 的旧随机成长系统；已有保护时拒绝重复使用，有可转换项时保留等级及成长经验，转换取最高旧阶数、最多保护 V。无可转换项时需要仍有成长空间、增加一级成长并清空该级经验。普通附魔、品质、磨损和装备 UUID 保留。基础合成管线将该配方视为固定品质且免经验的装备维护，受损装备可使用，不受制造重掷品质影响。

## 金属棒模板升级（0.1.6）

接入本体 0.1.10 的 `mite:equipment_upgrade_smithing_template`。七条原生 `minecraft:smithing_transform` 路线为铜／银／金棒各自升级铁棒，以及铁→远古金属→秘银→艾德曼→振金。模板、原棒、目标材质锭各消耗一个；采用原版锻造台，不要求额外金属粒或棒核心。

铜、银、金、铁棒保留原有直接制作配方；四种更高阶棒的旧工作台配方已替换，资源生成脚本同步修改。棒核心物品保留以兼容现有存档，不再作为棒升级的材料。JEI 直接使用其原生锻造分类，无额外自定义分类。

使用本体模板的装备转换逻辑，保存品质、名称、普通附魔、成长 UUID／等级／经验／副词条，以及拓展宝石、磨具和独立锻造组件。输出采用新材质的固有属性，磨损按比例四舍五入转换；单次预览不消耗输入。

## 副手材质灯笼

原光源核心采用共用的立体灯笼结构，保留 `dynamic_core_mithril`、`dynamic_core_adamantium` 存档身份，增加铜、银、金、铁、古代金属和振金材质。材质差异体现在金属框颜色和最大耐久；各材质提供相同的持有者夜间视野增强，不改变世界光照或怪物生成。

| 材质 | 最大耐久 | 连续使用时间（20 TPS） |
| --- | --- | --- |
| 铜 | 1600 | 6 分 40 秒 |
| 银 | 2400 | 10 分钟 |
| 金 | 3200 | 13 分 20 秒 |
| 铁 | 4800 | 20 分钟 |
| 古代金属 | 6400 | 26 分 40 秒 |
| 秘银 | 9600 | 40 分钟 |
| 艾德曼 | 16000 | 66 分 40 秒 |
| 振金 | 25600 | 106 分 40 秒 |

只有副手未耗尽的灯笼生效；背包和主手中的灯笼不生效、不磨损。生存模式每 10 tick 消耗副手灯笼 2 点耐久，最后不足 2 点仍可消耗，耗尽后物品保留并停止增强。创造模式免磨损，旁观模式不生效。照明直接接入持有者客户端光照计算，取下或耗尽即可恢复原视野，不添加普通夜视药水，不削弱或移除已有药水效果。

各材质统一工作台配方为 ` I ` / `IGI` / `ITI`：I 为对应材质锭（5 个），G 为玻璃（1 个），T 为火把（1 个），产出 1 个满耐久灯笼。中文和英文提示明确副手要求及耐久消耗。

## 独立强化规则

独立锻造等级与成长等级分别保存。铁和远古金属最多 3，秘银最多 5，艾德曼最多 7，振金最多 10；远古金属和秘银需要秘银台，艾德曼需要艾德曼台，振金需要振金台，铁台可强化铁。

| 本次等级变化 | 材料 |
| --- | --- |
| 0 → 1 | 金锭 1、铁锭 1、铁强化石 1 |
| 1 → 2 | 金锭 1、铁锭 2、铁强化石 1 |
| 2 → 3 | 金锭 2、铁锭 2、铁强化石 1 |
| 3 → 4 | 金锭 2、铁锭 2、铁强化石 2 |
| 4 → 5 | 金锭 1、秘银锭 1、红石 1、秘银强化石 1 |
| 5 → 6 | 金锭 2、秘银锭 1、红石 2、秘银强化石 1 |
| 6 → 7 | 金锭 2、秘银锭 2、红石块 1、秘银强化石 1 |
| 7 → 8 | 恶魂之泪 1、艾德曼锭 1、秘银锭 2、艾德曼强化石 1 |
| 8 → 9 | 恶魂之泪 2、艾德曼锭 1、秘银锭 2、艾德曼强化石 1 |
| 9 → 10 | 恶魂之泪 2、艾德曼锭 2、秘银锭 2、艾德曼强化石 1 |

当前等级小于 4、4–6、7 起的基础失败率分别是 35%、55%、65%。斧和战锤每比铁高一个材料阶，分别降低 2、3 个百分点。耗时为 `(400 + 当前等级*200) / (0.25 + 斧材料阶/5 + 战锤材料阶/4)` tick，四舍五入。源斧耐久消耗序列为 `2048,2048,3072,3072,4096,4096,6144,6144,8192,8192`，战锤为 `2048,3072,3072,4096,4096,6144,6144,8192,10240,10240`。

失败消耗本次材料和一半工具耐久，损失装备剩余耐久的 5%（当前等级小于 7）或 10%，不降锻造等级，保留输入装备。成功消耗完整工具耐久，设备从输入槽移动至输出槽。操作中槽位锁定，成功/失败和失败发生时间在开始时只掷一次并存档，重载区块不会重掷。

锻造增强系数为 `pow(1.028, 锻造等级*2.28)-1`；应用于相应武器攻击、工具挖掘与护甲保护。成长经验倍率为 `1 + 锻造等级*(锻造等级+1)*0.025`。相应等级的源品质奖励保留，但不降低已有更高品质。

万能强化石在旧 ITE 正式注册且有配方，但旧十段锻造材料列表没有直接使用它。此处明确适配为可替代任意类型强化石，仅真正分配并消耗万能石时采用 50% 基础失败率；把多余万能石塞入空材料槽不会改变概率。

## 经济管线与保存

源钓鱼新增项的权重总计 180：垂钓凭证 36；苹果、马铃薯、香蕉、面包、胡萝卜、橙子各 16；铜、银、金、铁粒各 8；秘银、远古金属、艾德曼、振金粒各 4。旧 RIC 原鱼表的完整权重未随提供的 JAR 给出，不能声称还原了未知绝对概率。现代适配额外给当前鱼结果保留权重 100，在普通鱼结果上按总权重 280 抽取；源新增项之间比例完整保留，现代宝藏、垃圾、河豚/热带鱼等特殊鱼不替换。

钓鱼使用注册的 Global Loot Modifier，并且仅在 `minecraft:gameplay/fishing` 主表、实际 `FishingHook` 上运行。没有通过修改 `ItemFishedEvent.getDrops()` 的副本来假装改变收获。当前鱼饵、咬钩速度、远海大鱼管线、宝藏/垃圾与经验继续保留。

旧 Extreme 禁用原图书管理员和铁匠、创建新职业。依用户“其余冲突保留当前”选择，现代实现保留原版及基础 R196 交易，向现有职业补充源交易；每新达到一个村民职业等级只尝试补充一次，记录已知行、职业和等级。读菜单不重掷；村民保存和补货沿用原实际 `MerchantOffers`；更换职业时只失效本扩展的补充记录。

书价遵循普通 `等级*5 + 0..9`、单等级特殊书 `35 + 0..9`、最高总价 64；扩展范围附魔书最高 I、时运最高 III。附魔从当前服务端实际注册表抽取，排除诅咒和只用于装备成长的经验副词条。交易输入按实际物品堆叠上限拆至两个支付槽，避免源 32 绿宝石或 8 金属锭的旧堆叠前提产生不可支付交易。每个新增报价有 7 次使用。

成熟作物物理破坏与附魔收割只在真正成功后发起凭证抽签；人工 `BreakEvent` 权限检查通过作用域抑制发奖，避免被取消的收割或双重事件提前/重复产出凭证。村民凭证绑定真实交易事件，40 tick 节流是对旧待初始化交易阶段的现代适配。

- 不加入 ITF、商店插件的可选兼容或禁用玩法 mixin，遵循用户明确选择。
