# MITE: Modern ITE 0.3.5

November 15, 2026. Developed by NingMeng123.

## Changes

- Fixed Protection Tome conversion for armor growth modifiers in both current and legacy saved-data formats. Converted modifiers now grant the effective Protection growth modifier, retaining the highest converted rank within its cap and preserving existing growth progress and other equipment data.
- Fixed Protection Tome crafting previews and completion for armor without an assigned growth identity. Tome application works through the inventory crafting grid and workbench, including normal and Shift pickup.
- Added a Protection Tome tooltip explaining how to combine it with armor in a crafting grid.
- Restored ordinary skeletons to 6 base health. Existing skeletons with the former 15-health profile migrate on loading, preserving their injured-health ratio, independent health modifiers and calendar growth.
- Updated the minimum required MITE: Modern version to 0.3.5.

Build file `MITE-Modern-ITE-0.3.5.jar`.

Requires MITE: Modern 0.3.5 or newer, Minecraft 1.21.1, Java 21 and NeoForge 21.1.259 or newer within the 21.1 series. Install the addon and core mod on both client and server.
