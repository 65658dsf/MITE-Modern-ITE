# 0.2.16 配套发布

开发署名：NingMeng123。日期：2026-10-27。

Minecraft 1.21.1、NeoForge 21.1.259。安装 `mite-0.2.16.jar` 和 `modern-ite-0.2.16.jar`，替换旧的同类JAR，客户端与服务端使用同一组版本。拓展最低本体依赖为0.2.16。

时间领主使用秘银剑、秘银甲和时钟，出生装备沿用现有日期成长机制且不会低于秘银材料。召唤的原版狂风人有额外生命、伤害和移速，每5秒最多一只，每位领主累计最多6只。定时时间迟滞使玩家的模拟、输入和动作以原速1/5推进，世界与其他生物保持原速。详情及命令见[时间领主](time-lord.md)。

时间领主按现有骷髅方式适配Fresh Animations，已用用户的Fresh Animations 1.10.4和EMF／ETF验证。命令或刷怪蛋生成的时间领主，其随从继承手动遭遇的准入，修复第一天开局保护导致无法召援的问题；仍须锁定可见的生存／冒险玩家，创造观察不会触发战斗技能。装备、动作适配和此前追击修复一并保留。

配套本体采用已经发布并用于召援回归的0.2.16成品，SHA-256为 `086683f00d4c531e54d005b9090298b080ca40f9ab5cc75a1ad767e9c1672260`。

验证：38项JUnit与19项时间领主专项通过。功能冻结后的全量384/388通过；同一配套本体下，修复前HEAD的对应命名空间基线320/324通过，同名4项均为旧早期装备锁断言。GPU动作检查及本次召援修复的详细结果见[验证记录](verification.md)。
