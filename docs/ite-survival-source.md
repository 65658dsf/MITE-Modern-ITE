# ITE 生存事件来源与适配

开发署名：NingMeng123。

依据本地 MITE-ITE 2.0.28 的 EntityPlayerTrans.injectTick、EntityTrans.injectNetherFire，以及 Configs.GameMechanics；核对了整个 ITE 与 Extreme 反编译目录的读写引用。

| 机制 | 有效来源 | 本实现 |
|---|---|---|
| 淋雨 | 计数上限3600，达到后每tick虚弱I 3600tick；离雨每tick减1 | 玩家持久化独立计数；不增加原有湿冷营养代谢倍数 |
| 下界热脚 | 显示第96天后，能着火实体的扩展碰撞箱接触地狱岩，每21次检查视为一次火接触；没有靴子条件 | 所有非免火实体每21个接触tick一次1HP火伤；不改方块、不额外点燃，不替换原有地幔热伤 |
| 地底随机传送 | 默认132000tick，提前6000/1200tick和最后10秒预警；离地底计数减1；秘银符文种子随机 | 复用本体秘银符文坐标与安全落点检查，保持同维度；不清理方块，不建传送门；落点失败保存待传坐标，每200tick重试 |
| 地底疲劳 | ITE原72000/108000tick分两阶段 | 0.2.1复用Extreme原计数与离开一天恢复机制，接入开关和两阶段配置；默认54000/108000tick缓慢I/II，不叠加两套计时 |
| 下界72000疲劳 | 原netherDebuffTime缺少递增路径 | 用户要求补齐后，0.2.1新增真实停留累计、离开递减与持久化，默认72000tick挖掘疲劳II，支持关闭 |

当前本体已有淋雨/浸水/低温营养代谢、地幔热伤、符文门落点安全检查；这些继续复用。环境计数不新增最高日期存储。创造与旁观模式跳过新增环境惩罚，计数与随机传送待办跨保存及玩家复制保留。

随机传送不重置Extreme地底疲劳，因为没有离开地底世界。生命与装备成长的最高历史日期也不受传送影响。

`TileEntityBeaconTrans` 与 `ClientPlayerTrans.modifyCraftingPeriod` 的有效信标制作加速使用本体服务端制作周期入口实现：一到四层分别提供25%、40%、60%、85%，周期除以 `1+加速` 后四舍五入，仍至少25tick。只在原生信标实际向玩家施加已选择的效果时刷新160tick；多个来源取最大值，破坏信标立即移除该来源，离线或换维度清理，短期缓存不写入玩家存档。已有制作进度payload继续同步最终周期。

`MobSpawnerTrans` 的玩家近场加速接在原生刷怪笼有效倒计时自减之后，再减2并限制不低于0。近场盒横向为生成半径的两倍、纵向为生成半径；原生激活半径、生成检查与周边生物限制保持原样，旁观者不触发额外加速。方块刷怪笼与刷怪笼矿车共用同一路径。

0.2.1已按用户要求开放两种金苹果使用耗时，默认32/32tick，营养与药效保持原规则；四种宝石献祭经验默认500/250/50/25并分别可调，新增石英等级55上限。金属块升级使用独立金属升级炉与配方类型，四项配置控制6000/2和9000/1的耗时/块数，不替换普通熔炉烧制宝石碎片的路线。

`EntityWolfTrans` 的有效分支让未驯服野狼在64格内寻找手持肉、可以看见的生存玩家；驯服狼、创造玩家、旁观者和原有女巫盟友不参与。旧函数名虽提到快捷栏，其非手持肉分支实际上不能进入有效循环，因此未扩展成扫描整快捷栏。该目标接入现有目标选择器，保留原有复仇、主人保护与饥饿猎物行为。

振金粒砾石掉落分支与现有基础矿物随机树冲突，保留现状；父ITE振金征服者VII、额外附魔数和特殊高阶附魔台规则与用户保留的当前附魔入口冲突。本扩展征服者普通附魔和成长候选上限为V，不声称提供VII。怪物实际持有暴击附魔时，依源每阶20%触发，伤害乘1.5再增加每阶0.4；玩家与怪物分别从其原生伤害入口处理。
