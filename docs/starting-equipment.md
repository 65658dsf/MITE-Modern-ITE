# 开局火把、燧石与铜甲升级

维护者：NingMeng123。日期：2026-10-22。

装入本扩展后，小燧石的掉落、拾取前实体和玩家旧存量按1:1转为大燧石。大小燧石互转配方被移除，箭、燧石钓竿和拆箭同步使用大燧石；创造分类及JEI隐藏小燧石。

铜护甲升铁采用工作台配方：对应铁护甲的标准铁锭形状，加其中空位的一件铜护甲。头盔、胸甲、护腿、靴子分别使用5、8、7、4个铁锭；至少使用铁级工作台。产物继承品质、磨损比例、附魔、成长及扩展组件。原铜工具及其他材质路线继续使用现有升级方式。

新玩家首次登录后，在有支撑、无液体且可替换的脚下位置放置一根火把。出生点不适合时等待安全位置；不会替换实体方块或水。标记随玩家保存并在死亡复制，重登及死亡不会再次放置。已有游玩记录的旧玩家不追补。

对应GameTest命名空间为`modern_ite_starting`与`modern_ite_feedback`。自动验证以实际测试输出为准，画面与操作手感仍需游戏内复测。

2026-10-22验证：`build`、30项JUnit与271项完整服务端GameTest全部通过，日志`build/feedback-regression-final.log`。JAR的261个生产类逐字节匹配编译输出、543份JSON可解析，测试类及结构不进入发布包。配套本体1673项JUnit、2261项完整服务端GameTest通过；未操作用户游戏进行画面或真实多人验收。
