# MITE: Modern ITE 0.3.8

November 21, 2026. Developed by NingMeng123.

## Changes

- Added natural Nether spawning for eligible ITE hostile mobs.
- ITE upgrade tables now validate the requested target upgrade tier.
- Added the Eye of the Bastion, adjusted golden apples and ported legacy Extreme achievements.
- Updated the minimum required MITE: Modern version to 0.3.8.

Build file `MITE-Modern-ITE-0.3.8.jar`.

Requires MITE: Modern 0.3.8 or newer, Minecraft 1.21.1, Java 21 and NeoForge 21.1.259 or newer within the 21.1 series. Install the addon and core mod on both client and server.
