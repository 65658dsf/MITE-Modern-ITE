# 灯笼铁砧修复

开发署名：NingMeng123。

八种灯笼可在铁砧中使用对应材质的金属粒修复，部分损耗和耐久耗尽均可。修复后恢复副手照明，并保留名称、附魔及自定义组件。金属锭、其他材质的金属粒和满耐久灯笼不产生修复结果。

铁砧等级沿用装备规则：铜／银／金同档，其后依次为铁、古代金属、秘银、艾德曼、振金；需要同档或更高铁砧。磨损后的铁砧仍保留原材质等级。

制作灯笼使用五锭，对应装备修理成本为十粒。每粒最多恢复耐久上限的十分之一，完全耗尽的灯笼使用十粒可修满；不足一粒修复量的末尾处理沿用本体规则。实际取出结果时扣除材料并按恢复耐久磨损铁砧，预览和无效取出不收费，普通修理不消耗经验。

实现只扩展本体 `MaterialAnvilRules.previewRepair` 的灯笼材质识别，复用真实铁砧菜单的等级检查、消耗、磨损和取出验证。全局装备材质识别保持原状，灯笼不会因此新增熔炼回收或装备掉落限制。

`LanternRepairGameTests` 覆盖八种灯笼、八十组实体铁砧容量组合、错误材料、普通与 Shift 取出、组件保留、修复后照明、重复取出及满背包无损耗；与现有六项灯笼测试组合运行。独立输出及固定本体依赖的验证记录位于 `build/verification/lantern-repair/`。
