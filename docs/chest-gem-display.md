# 胸甲宝石星形勋章

开发署名：NingMeng123。日期：2026-10-29。

头盔、胸甲、护腿、靴子和当前主手武器／工具的宝石统一显示在胸口，每颗以一颗透亮的玻璃六芒星表示，星面仍可透见装备底色。六个尖角采用两个等边三角形相交后的外轮廓，主体尺寸保持小巧。细轮廓以宝石原色区分类型，玻璃正面为明显的流动彩色渐变；同类型不同阶级在相同时间和位置保持相同外观。更换装备、切换主手或取出宝石时同步更新。

胸前以小型勋章式排列，每排五颗，最多五排，共25颗。按实际显示数量先填上排，再填下排；未满五颗的行水平居中，空孔不画星。单星尺寸从0.09缩至0.07，列距1.4、行距1.5模型像素，完整阵列仍位于胸部区域。

五件装备最多共有40颗宝石；不超过25颗时全部展示，超过时按用户要求随机抽取25个实际孔位，无放回。同一角色、同一组镶嵌内容的选择保持稳定，不随帧数、时间或视角变化而跳动；装备内容变化后重新选取。选中后仍沿用原装备和孔位顺序排列，不轮换页面。

读取既有 `gem_sockets_v1` 八孔数据，来源顺序为胸甲、头盔、护腿、靴子、主手，单件顺序沿用镶嵌台顺序；空孔不占布局位置，重复宝石分别显示。护甲须处于正确装备槽位；主手沿用正常镶嵌白名单，兼容剑、战锤、匕首及工具，手持护甲、盾牌等不支持镶嵌的物品不计入。副手和背包内装备不计入。读取实际存储孔位，不合并同类型等级，不改变装备数值或宝石属性效果。

所有星饰只贴在身体胸口，头、腿、脚和武器本体不绘制星饰；无胸甲时贴在皮肤外套层外侧，有胸甲时贴在胸甲表面。

星饰随身体模型转动、下蹲和幼体缩放移动；普通和纤细玩家、人形生物及盔甲架共用显示层。该层在原盔甲及振金星光之后绘制。隐身时仍可见的盔甲继续显示星饰。

六芒星有细窄轮廓、真实浅侧壁、斜切亮边与略微隆起的正面切面。上方与左侧斜边更亮，下缘保留较深的类型色；各个侧面采用不同方向的法线随光照变化，转身时能看到薄厚度。整体厚度约0.128模型像素，外侧平面轮廓和原排列尺寸不变。深色轮廓只位于窄环，中央没有遮挡底纹的暗底。

玻璃正面以约12秒周期，连续经过红、橙、黄、绿、青、蓝、紫等色相，幅度明显；同一颗星的不同位置也采用不同颜色，经顶点插值形成星面内部的柔和过渡，各星错开相位。正面采用饱和度84%、明度100%的颜色，中心只加入少量高光，避免再次被浅色混合冲淡。侧壁、细轮廓和斜边固定保留宝石类型色，攻击、耐久仍区分为暖银与冷钢色：

| 宝石类型 | 轮廓颜色 |
| --- | --- |
| 攻击 | 暖银 `#D8D4C8` |
| 生命 | 红色 `#DE4352` |
| 保护 | 紫色 `#A15CDC` |
| 恢复 | 蓝色 `#528CE1` |
| 效率 | 青绿 `#4CC59E` |
| 耐久 | 冷钢 `#687E93` |
| 速度 | 金色 `#DFBB43` |
| 防火 | 浅蓝 `#7DC3DB` |
| 防爆 | 黄绿 `#A6CC4D` |
| 饱食 | 橙色 `#E48643` |

星面、侧壁与斜边均采用半透明绘制，主体跟随正常光照；斜边增加浅色高光，正面更通透，形成有切面的玻璃观感。柔和自发光晕从六芒星轮廓向外渐隐，以约三秒周期轻微呼吸。每颗星独立、不定时地闪亮：约2.5～7秒间隔出现一次约0.45秒的闪光，快速变亮、柔和消退。闪光带有偏白亮心和细小的X形光芒，参考亮心与放射光的观感，尺寸仍贴合小星饰。未闪时亮心和光芒完全透明。

各星的闪光相位与每次间隔由角色身份及本颗星的位置独立确定，同一时刻可以各自处于未闪、变亮或消退阶段；帧率和视角不会重置时序，部分tick连续插值。星形位置保持固定，正面不透明度约42%～49%，颜色更清晰且仍能透出装备底纹。光晕与闪光移到浮雕最高点前方，沿用正面中心的渐变色；闪光通道全亮但仍使用透明混合。渲染复用原版白色纹理及原生透明／自发光通道，光效不生成粒子实体。

生产代码位于 `client/gear/ChestGemLayer.java` 与 `ChestGemRendering.java`。装备组件沿用既有保存和网络同步，客户端渲染类只在客户端加载。

## 实机验证

`ChestGemClientAudit` 通过完整原生玩家和盔甲架渲染器检查实际GPU图像及星形顶点，并验证十类星色可分辨、同类不同阶级外观一致。使用隔离新世界运行：

```powershell
.\gradlew.bat -I tools/chest-gems-audit.init.gradle runClient `
  -PmodernIteClientDirectory=build/verification/chest-gems-20261029/client
```

默认报告为该目录的 `client-audit.json`，截图位于 `mob-render-audit/`。结果与交付包记录见 [验收记录](verification.md)。
