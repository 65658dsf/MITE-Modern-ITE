# 首次发现玩家与 Boss 换锁

开发者：NingMeng123

日期：2026-10-27

普通僵尸、骷髅及其扩展变种复用本体的主动目标选择器。普通场景首次发现玩家须通过自身视线，修复挖掘能力、高处玩家候选以及附近蝙蝠造成的视线豁免。地下近战怪物另可验证附近24格玩家的完整可步行路线后建立追击，完全封墙及残缺路线不成立；每只怪40～49刻探测一次，全服每刻最多两次新探测，并复用本体路线缓存。怪物已发现玩家后，玩家躲进墙后仍可按原有目标记忆追击；受击和既有仇恨继续工作。

扩展 `MobAbilities` 中的僵尸 Boss 周期随机换锁还有独立入口。本轮对新候选增加 `SourceMonsterTargeting.canSee` 检查；当前目标即使暂时被遮挡仍是合法候选。召唤继承、实体替换、伤害反击及刷怪笼事件的目标转接继续采用原规则。

`BossTargetSightGameTests` 调用真实 Boss 能力 Tick，检验隔石墙的陌生玩家不能抢锁、拆墙后能正常选中，以及已见玩家躲墙后仍可保留。在本轮独立 AI 修复快照中，编译、38 项 JUnit 和全部 369 项必需服务端 GameTest 已通过；日志为本体项目的 `build/verification/path-targeting-scoped-ite.log`，基线和文件校验值见交付包的验证记录。

本轮 JAR 版本保持 0.2.14，需使用同轮修复后的 MITE 本体。修复前已经建立的仇恨不会因新规则被主动清空；复测首次发现时应使用此前未见过该玩家的新怪物。
