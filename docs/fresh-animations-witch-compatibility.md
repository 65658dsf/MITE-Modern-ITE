# 女巫旧皮肤与 Fresh Animations

作者：NingMeng123

女巫领主和流浪女巫保留本扩展原有的 64×128 皮肤及红眼发光层。Fresh Animations 的女巫模型会重新组织头部、面部和帽子；直接把这套模型用于旧皮肤，会把面部取色及帽子分段建立在另一套布局上。

`SourceWitchModel` 使用独立的 `modern_ite:source_witch` 模型层绘制原有几何和 UV；另建标准女巫模型，交给已安装的 EMF/Fresh Animations 计算动作。只把动作传给可见模型，不复制其方块、面部贴图或纹理路径。

Fresh Animations 实际头部位于躯干子节点中。适配读取这个节点的累计矩阵并转换为原模型的头部姿态；按方块中心校正其向前伸出的偏移，避免只复制空的标准头节点。帽子保留原先相连的所有分段位置，只叠加动画中的局部摆动。鼻子保留原生饮药动作。

未安装 EMF，或资源包不提供女巫动画时，继续使用原生女巫动作。其他女巫资源包没有相同头部节点时，头部使用标准骨骼动作回退；旧皮肤、红眼及完整帽子仍保留。自定义旧皮肤没有 Fresh Animations 所需的分离眼球调色区，因此不移植其面部纹理方块。

客户端 `MobRenderRegressionAudit` 的两种女巫样本会额外执行 `WitchFreshAnimationsAudit`：逐方块比较原生几何及全部 UV，检查帽子分段原始支点，捕获真实步行动画，并在隐藏衣服和帽子的暗光头像中检查红眼像素。启用 Fresh Animations 时，还要求成功采样真实动画和重组后的头部节点。结果与截图写入该审核原有的独立输出目录。

2026-10-20，0.2.6 的隔离构建在有 FA 和无 EMF 的两个客户端中分别通过 45 个纹理读取、15 个重点 GPU 绘制。两种女巫均保持原生 15 个方块的几何与 UV；FA 运行中暗光头像红眼均超过 70 像素。骷髅僵尸也保留原 64×64 粗四肢网格，只借用骨骼姿态；相位苦力怕使用自身命名空间的紫眼纹理，不再受资源包修改末影人眼部 UV 的影响。主模组与扩展需一起更新至 0.2.6。
