# MITE: Modern ITE

开发署名：**NingMeng123**。拓展版本 **0.2.7**，Minecraft **1.21.1**，NeoForge **21.1.259**，模组 ID `modern_ite`。

2026-10-22 加入小燧石直接替换大燧石、铜甲工作台升铁及新玩家脚下火把，规则与复测见[开局与装备调整](docs/starting-equipment.md)。本体同步的生存、合成、矿物高度与生物桶Ctrl修复需要配套更新本体。30项JUnit、271项服务端GameTest通过，用户已授权提交本批变更。

本工程把旧 **MITE-ITE 2.0.28** 与 **Extreme LH 0.6.6** 的移植内容放入同一个拓展模组。当前版本 **0.2.7**，运行时需要 **MITE: Modern 0.2.7 或更新版本** 的配置与玩法接口。旧版 ITE 和极难 JAR 只作为本地规则、资源证据，不放入游戏或发布包。

新增疯狗、女巫矮冬瓜诅咒和末影人大头：疯狗常驻速度 I，咬伤后使玩家失控挥砍 6 秒；矮冬瓜诅咒让生命、攻击属性和体型减半；末影人的头与发光眼睛放大为 2 倍。具体生成、解除方式及测试命令见 [三项生物更新](docs/mob-additions.md)。

主模组设置页左上角有“ITE 扩展设置”，拓展自己的模组配置按钮也可进入。拓展已接入92项参数，包含玩家/怪物渐进伤害、征服者、环境疲劳、献祭、独立金属升级炉、交易与动物规则。主模组矿物页分别配置主世界和地底的生成倍率，默认1，2为双倍、0.5为一半、0关闭；高级频率和概率仍独立保留。配置位置、单位和旧JSON对应范围见 [玩法配置说明](docs/configuration.md)。

复活传送阵采用黑曜石祭坛、金边、四面下界之星与青色水晶，外覆封顶透明玻璃展示罩。放置后绑定主人，罩内悬浮展示该玩家的缩小皮肤模型，约60秒旋转一圈，兼容普通与纤细手臂及皮肤外层；空手右键可查看主人。仅主人可以破坏，其他玩家在生存与创造模式下均无法拆除，主人离线时仍受保护。归属和皮肤资料随世界保存并同步给其他客户端，主人离线时仍可展示已保存的皮肤。旧存档的复活阵在主人登录或操作时自动补全归属，原有单人单阵及死亡消耗规则保留。

已为全部12种扩展附魔提供简体中文和英文描述，兼容 Enchantment Descriptions（附魔描述）1.21.1 / 21.1.11。客户端安装该模组及其依赖后，附魔书和附魔装备的提示中会显示效果说明，显示条件遵循其配置。描述通过标准 `.desc` 翻译条目提供；可配置的概率、伤害、恢复量和冷却以当前玩法配置为准。

## 构建

使用 Java 21，在本目录执行：

```powershell
./gradlew build
```

默认编译、运行依赖 `../miteto1.21.1neoforge/build/libs/mite-0.2.7.jar`，可通过 `-PmiteJar=绝对路径` 指定。基础模组通过普通外部依赖加载，不嵌入拓展 JAR。

```powershell
./gradlew test
./gradlew runGameTestServer
./gradlew runClient -PmodernIteClientAudit=true
./gradlew runClient -PmodernIteMobRenderAudit=true
./gradlew runClient -PmodernIteJeiAudit=true
./gradlew runClient -PmodernIteLanternAudit=true
./gradlew runClient -PmodernIteResurrectionAudit=true
```

第一条客户端命令在独立 `run-client` 目录执行标题页资源检查，不加载存档。第二条在独立 `run-mob-render-audit` 目录新建一次性平坦测试世界，实际绘制14种重点生物，检查大头效果与粒子，并保存像素检查与截图；两者均在检查后退出该测试实例。测试类只在开发源集，不进入发布 JAR。

第三条客户端命令临时加载开发 JEI，在独立 `run-jei-audit` 测试世界检查真实配方页、原生左侧锻造台列表与界面入口，并保存截图后退出该实例。普通开发客户端需要 JEI 时使用 `-PmodernIteWithJei=true`。JEI 不打入发布包，实际安装时由玩家选择是否加载。

第四条在独立 `run-lantern-audit` 目录新建测试世界，检查三种保留材质的立体灯笼模型、15 个实际物品显示样本、副手照明即时开关和药水夜视兼容，输出 `build/verification/lantern-client-audit.json` 及灯笼预览图。正常展示和可合成的灯笼为艾德曼与振金，秘银仅为旧存档兼容保留，隐藏于创造栏与 JEI 且无配方。此处说明命令的检查范围，不表示当前版本已完成客户端验收。

第五条在独立 `run-resurrection-audit` 目录的标题页检查复活阵烘焙模型、贴图和方块实体渲染器，并通过真实 GPU 绘制普通/纤细皮肤及不同旋转时刻，输出 `build/verification/resurrection/audit.json` 和 `preview.png` 后退出测试实例。

安装 JEI 后，对可强化装备查看配方或用途，可以在唯一的“强化锻造”标签中看到各级强化步骤，普通强化石和万能强化石分别展示。左侧随当前页列出可用台：铁装备为四台，远古金属/秘银为秘银、艾德曼和振金台，艾德曼为艾德曼和振金台，振金只列振金台；同屏多条配方时，列出它们共同可用的台。强化台界面点击进度箭头也能打开强化配方，宝石镶嵌台不启用此入口。

振金熔炉接入本体的热量配方分类，JEI 中可查询其原料、燃料、产物和耗时，左侧列出振金熔炉；熔炉界面点击进度箭头可直接打开。配方显示保证产物，额外 5% 增产概率另有说明。

金属棒使用含升级模板的新本体 0.1.10，在原版锻造台放入升级模板、原棒和一个目标材质锭，沿“铜／银／金→铁→远古金属→秘银→艾德曼→振金”逐级升级。铜、银、金、铁棒保留直接制作；旧的四种高阶工作台升级配方已替换，不再消耗金属粒或棒核心。升级保留名称、附魔、品质、成长、宝石、磨具及独立强化，磨损按新最大耐久的比例换算。JEI 使用原生锻造分类显示这些配方。

立体手提灯笼仅艾德曼与振金正常展示并可合成，分别具有 8000、12800 点耐久；旧秘银灯笼保留物品 ID、资源和已有磨损以兼容存档，耐久为 4800，隐藏于创造栏与 JEI 且无配方。铜、银、金、铁、古代金属灯笼及其专用资源和语言已移除。保留的三档照明相同，只有放在副手且耐久未耗尽时生效，取下立即停止。生存模式每 10 tick 消耗 2 点耐久，20 TPS 下秘银、艾德曼、振金分别可连续使用 20 分钟、33 分 20 秒、53 分 20 秒，耗尽后保留灯笼；创造模式不磨损，旁观模式不生效。艾德曼和振金灯笼可用对应材质的 5 个锭、1 块玻璃和 1 个火把制作；三档保留灯笼均可用对应金属粒在同档或更高铁砧修复。灯笼只改善持有者的夜间视野，不改动药水夜视或世界方块亮度。

资源复现脚本为 `tools/generate_gear_assets.py` 和 `tools/generate_content.py`，使用本地参考 JAR。素材原路径和 SHA-256 记录在 `modern_ite/content-provenance.json`；本次现代配方适配与资源复用也写在其中。
